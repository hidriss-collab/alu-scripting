# Regular Expressions Project

This project is part of the ALU Scripting curriculum.  
It focuses on learning and practicing regular expressions in Ruby using the Oniguruma library.

## Requirements
- All scripts are written in Ruby.
- Each script starts with `#!/usr/bin/env ruby`.
- Scripts take one argument and apply a regular expression using the `scan` method.
- All regex patterns are built for the Oniguruma library.

## Tasks
1. **0-simply_match_school.rb**  
   Match the word `School`.

2. **1-repetition_token_0.rb**  
   Match specific repetition patterns.

3. **2-repetition_token_1.rb**  
   Match another repetition pattern.

4. **3-repetition_token_2.rb**  
   Match a different repetition pattern.

5. **4-repetition_token_3.rb**  
   Match repetition without square brackets.

6. **5-beginning_and_end.rb**  
   Match strings starting with `h` and ending with `n` with one character in between.

7. **6-phone_number.rb**  
   Match a 10-digit phone number.

8. **7-OMG_WHY_ARE_YOU_SHOUTING.rb**  
   Match only capital letters.

9. **8-textme.rb**  
   Extract sender, receiver, and flags from TextMe logs.
